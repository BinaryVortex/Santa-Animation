# Santa Animation

A small, festive animation of Santa built using only HTML and CSS — no JavaScript required.

![Preview - Santa Animation](./Screenshot%202024-12-09%20013242.png)

(If the image above doesn't render outside GitHub, here's the raw image URL you can use:

## Demo / Preview

- Open `index.html` in any modern browser to view the animation.
- For live editing, use a static server or your editor's Live Server extension.

## Features

- Pure CSS animation (keyframes, transforms)
- Lightweight and easy to customize
- No external libraries or scripts

## Files

- `index.html` — HTML structure for the animation
- `styles.css` — CSS styles and animations
- `Screenshot 2024-12-09 013242.png` — Preview screenshot shown above

## How to run locally

1. Clone the repository:
   git clone https://github.com/BinaryVortex/Santa-Animation.git
2. Open the project folder and open `index.html` in your browser:
   - Double-click `index.html`, or
   - Run a simple static server (Python example):
     - Python 3: `python -m http.server 8000` and open `http://localhost:8000`

## Customization

- Colors: edit CSS variables or color values in `styles.css`.
- Speed: adjust animation durations in `styles.css` (search for `animation-duration` / `animation`).
- Size: change container widths/heights or scale with transforms.

## Notes & Compatibility

- Tested in modern Chromium-based browsers and Firefox.
- Since this is pure HTML/CSS, it should work without JavaScript enabled.
- If any parts look misaligned, check browser zoom and default font rendering.
